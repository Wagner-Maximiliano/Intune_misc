Policy Backup

Snapshot, version, and restore Intune Settings Catalog policies

Intune has no version history and no undo. This snapshots every policy, keeps a dated history only when content genuinely changed, and can restore from any past version.

  • JSON snapshots, one per policy per run
  • Versioned Excel workbook — new sheet only on real change
  • SQLite history database, additive and idempotent
Restore is create-only — it never overwrites an existing policy, and prints original assignments for manual reapplication.

MDM/GPO Conflict Validation

Find where Intune is silently overriding Group Policy

Collects evidence from co-managed devices — including Windows' own Blocked Group Policies table — and correlates it against a GPO→CSP mapping catalogue built from local ADMX files.

  • Interactive self-contained HTML report per device
  • SQLite history of findings across runs
  • Full evidence ZIP per device for audit
No agent, no cloud service, no credential delegation — fleet runs use a Copy delivery mode that avoids the double-hop problem entirely.

Your computer has been upgraded to Windows 11, version 24H2. Most of your day-to-day work looks the same. This page covers the things you will actually notice, and what to do about the few that need a decision from you.

APPLIES TO  Windows 11, version 24H2 (build 26100)   ·   AUDIENCE  All staff   ·   READING TIME  5 minutes

Read this first

  • WordPad is gone. It has been removed from Windows entirely. Use Word for documents, or Notepad for plain text.
  • You may see location pop-ups. Windows now tells you when an app asks for your location, even if location is switched off. See the Privacy and location section below.
  • An old network drive or scanner may stop connecting. Windows now requires a more secure connection to file shares. If a mapped drive or a scan-to-folder stops working, raise a ticket rather than changing settings yourself.

Files and File Explorer

File Explorer picked up several small quality-of-life changes.

[ IMAGE PLACEHOLDER — file-contecxual-menu.png — File Explorer right-click menu with labels ]
● Changed

The right-click menu now has labels

Cut, copy, paste, rename, share and delete used to be icons only at the top of the menu. They now have text labels underneath, so you no longer have to guess which symbol does what.

● New

Create 7-Zip and TAR archives without extra software

Right-click a file or folder and choose Compress to to build a 7z or TAR archive alongside the usual ZIP. Under Additional options you can also compress single files with gzip, bzip2, xz or Zstandard.

● New

Drag files onto the address bar

You can drop files directly onto any folder shown in the path at the top of the window, which saves opening a second window to move something up a level.

● New

Window previews show tabs

Hovering a File Explorer window on the taskbar, or using Alt + Tab and Task View, now shows a thumbnail for each open tab rather than one preview for the whole window.

Taskbar, Start and the system tray

Nothing has moved, but a few controls behave differently.

[ IMAGE PLACEHOLDER — quick-settings.png — Scrollable Quick Settings panel with Live captions ]
● Changed

Quick Settings scrolls

The panel you open from the clock and volume corner now scrolls through every available toggle instead of showing a fixed grid you had to edit first. You can still drag the toggles into whatever order you like.

● New

Pin apps to the taskbar by dragging

Drag an app out of the pinned area of the Start menu and drop it on the taskbar.

● Changed

Clearer network and VPN controls

The network icon animates while a connection is being established, Wi-Fi has a refresh button with a scan indicator, and VPN connections use a simpler toggle. Connecting to your VPN should take fewer clicks.

● Changed

Task Manager

Memory speed is now reported in MT/s rather than MHz, which is the correct unit. Ending a process releases it faster, and keyboard navigation and screen reader support have been improved.

Privacy and location

This is the change most people ask about after the upgrade.

[ IMAGE PLACEHOLDER — access-location-prompt.png — Prompt asking to allow an app to access location ]
● New

Windows tells you when an app asks for your location

A prompt now appears the first time an app tries to use your location or the list of Wi-Fi networks around you. It also warns you when an app asks unexpectedly, so you can refuse.

This still happens when location is switched off. The notification reports the request; it does not grant access. Some VPN clients, meeting-room and screen-sharing tools scan Wi-Fi to find nearby equipment, which is why they trigger it.

To stop the pop-ups Go to Settings > Privacy & security > Location and turn off Notify when apps request location. This hides the prompts and changes nothing else. Leave Location services as your IT team has set it.
● New

See which apps used your location

Apps that have used location or Wi-Fi information appear under Recent activity on the same Location page, and a location icon shows in the taskbar while an app is using it.

● New

Set a default location

If your PC cannot work out where it is, apps such as Weather fall back to a location you choose under Settings > Privacy & security > Location > Default location.

Network and Wi-Fi

[ IMAGE PLACEHOLDER — hotspot-qr-code.png — QR code used to connect to a Wi-Fi network ]
● New

Wi-Fi 7 support

If your laptop and the access point both support it, Windows can now use Wi-Fi 7. On corporate networks this depends on the access points installed at your site.

● New

Share a Wi-Fi network by QR code

Open the properties of a saved network under Settings > Network & internet > Wi-Fi to show a QR code another device can scan. Useful at home; corporate Wi-Fi passwords should not be shared this way.

● Changed

File shares require a more secure connection

Windows now insists that connections to file servers are signed, which prevents a common class of network attack. Older equipment that cannot do this, such as an ageing NAS or a scan-to-folder function on an old multifunction printer, may stop connecting.

If a drive or scanner stops working Raise a ticket with the service desk. Do not disable the setting yourself.

Power and display

[ IMAGE PLACEHOLDER — energy-saver.png — Settings, System, Power and battery, Energy saver ]
● New

Energy saver replaces battery saver

Energy saver reduces power use and now works on desktops as well as laptops. Switch it on from Quick Settings, or set it to start automatically at a chosen battery level under Settings > System > Power & battery.

● Changed

The screen may dim on its own

Content Adaptive Brightness Control adjusts brightness based on what is on screen to save power. Most people will not notice it. If it bothers you, change it under Settings > System > Display > Brightness & colour. Not every laptop supports this.

● New

Colour management page

Colour profiles for each connected monitor are managed in one place under Settings > System > Display > Colour management.

Printing

● New

Pause and resume individual print jobs

You can now hold a single job in the print queue instead of pausing the whole printer.

● New

Rename a printer

Give a printer a name that means something to you under Settings > Bluetooth & devices > Printers & scanners.

Accessibility and input

[ IMAGE PLACEHOLDER — hearing-aids-sound-properties.png — Sound properties for a hearing aid device ]
● New

Hearing aid support

Bluetooth LE Audio hearing devices can pair directly with a compatible PC to stream audio and take calls, with presets and ambient sound managed under Settings > Accessibility > Hearing devices.

● New

Voice Clarity on more devices

Echo, background noise and room reverb are reduced automatically in calling apps. It is on by default and needs no special hardware.

● Changed

Narrator scan mode is faster

Reading long documents, particularly in Microsoft Edge, is noticeably quicker.

● New

More keyboard layouts and newer emoji

German Extended (E1 and E2), Colemak and the 2018 standard Hebrew layout are available under Settings > Time & language > Language & region. Emoji 15.1 is supported.

Security

These are handled centrally. Nothing here needs action from you, but it explains changes you may notice.

● New

Windows protected print mode

Where enabled, printing uses only Windows' built-in modern print system, so manufacturer print software is no longer needed for supported printers.

● New

Personal Data Encryption for folders

Documents, Desktop and Pictures can be encrypted and unlocked with Windows Hello. If this applies to your device, you may be asked to sign in with Windows Hello before those folders open.

● Changed

Stronger protection of stored credentials

Local Security Authority protection is switched on automatically after the upgrade if nothing on your device conflicts with it. Very old add-ons that inject themselves into the sign-in process may stop loading.

● Changed

More devices qualify for device encryption

BitLocker hardware requirements have been relaxed, so device encryption is available on a wider range of machines.

Removed from Windows

● Removed

WordPad

Removed from every edition of Windows. Use Word for formatted documents and Notepad for plain text. Old .rtf files still open in Word.

● Removed

Windows Mixed Reality

The Mixed Reality platform and its headset support are no longer part of Windows.

● Removed

NTLMv1 and the Remote Mailslot protocol

Two obsolete network protocols have been removed or switched off. Only very old line-of-business software depends on them; if something stops authenticating, raise a ticket.
